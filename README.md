# Engineering Documentation Analysis System

Система для анализа и проверки рабочей документации по инженерным системам.

## Возможности системы

- Проверка документации на соответствие НТД РФ
- Анализ электрических и структурных схем
- Проверка кабельных журналов и спецификаций
- Расчет источников питания и аккумуляторов
- Формирование отчетов с замечаниями
- Ведомости объемов работ и оборудования

## Поддерживаемые инженерные системы

- Электроснабжение
- Электроосвещение
- Противопожарные системы (пожарная сигнализация, СОУЭ, пожаротушение)
- Сети связи (СКС, ЛВС, ВОЛС)
- Видеонаблюдение
- СКУД
- Охранная сигнализация
- АСУ, АСУТП

## Режимы работы

- Локальный
- Облачный
- Гибридный

## Требования к серверу

- CPU: 8 ядер (AMD-FX 8120 или аналог)
- RAM: 24 ГБ
- SSD: 60 ГБ
- GPU: опционально (HD 7950 3Gb)
- ОС: Proxmox

## Установка

### Быстрая установка

```bash
./install.sh
```

### Ручная установка

#### Backend

```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

#### Frontend

```bash
cd frontend
npm install
npm run build
```

## Запуск

```bash
# Backend
cd backend
source venv/bin/activate
python main.py

# Frontend (в режиме разработки)
cd frontend
npm run dev
```

## Доступ по умолчанию

- **Логин администратора:** `admin`
- **Пароль администратора:** `Admin@123`

**ВАЖНО:** Сразу после установки смените пароль администратора!

## Форматы входных файлов

- XLS/XLSX
- DOC/DOCX
- PDF
- DWG

## Форматы выходных файлов

- DOC/DOCX (отчеты)
- XLS/XLSX (ведомости, отчеты)

Система включает базу нормативно-технических документов РФ:
- ПУЭ
- ГОСТ
- СП
- ФЗ
- И другие
